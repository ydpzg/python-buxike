# 单章生产清单

## 内容

- [ ] 章节号、标题和老师出现在第一帧。
- [ ] 标题持续到开场旁白结束。
- [ ] 开场第一句就有字幕。
- [ ] 旁白解释概念，不直接读代码符号。
- [ ] 板书包含概念、作用和最小例子。
- [ ] 关键关系用卡片、终端或流程表示。
- [ ] 代码保留缩进。
- [ ] 代码不超出终端面板。

## 练习

- [ ] 练习有独立场景。
- [ ] 题目出现在标题和板书。
- [ ] 板书包含解决流程。
- [ ] 板书包含完整可运行的实现。
- [ ] 板书包含验收标准。
- [ ] 片尾重复本章练习名。

## 回顾

- [ ] 列出本章具体概念。
- [ ] 写出验证边界。
- [ ] 写出练习名称。
- [ ] 写出下一章主题。
- [ ] 不使用通用空标题。

## 音频与字幕

- [ ] 中文 TTS 发音正常。
- [ ] 数字和英文技术词发音可理解。
- [ ] SRT 与音频时间轴一致。
- [ ] SRT 不含 `|`。
- [ ] 问号和句号没有孤立换行。
- [ ] 修改文案后没有复用旧音频。

## 成片

- [ ] 时长 3–5 分钟。
- [ ] 1920×1080，30 FPS。
- [ ] 音轨完整，结尾不截断。
- [ ] 片头、练习、片尾静帧抽查通过。
- [ ] MP4、SRT、timeline 同名归档。
