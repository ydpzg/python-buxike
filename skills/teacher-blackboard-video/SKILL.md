# Teacher + Blackboard Video

## 何时使用

用户需要：

- 新建老师站在黑板前讲解的章节视频。
- 修复首屏、字幕、板书、代码缩进、练习页或片尾。
- 把一套章节内容批量渲染为 MP4、SRT 和 timeline。
- 审核成片是否适合初学者。
- 准备课程系列和 YouTube 播放列表信息。

## 先读

1. 仓库的 `README.md`。
2. `workflow/production-checklist.md`。
3. `workflow/lessons-learned.md`。
4. 要修改章节的 `content/*.py`。

## 核心规则

### 内容模型

每章是一个 `scene` 列表。每个 `beat` 是 `(旁白, 板书)`。

- 旁白负责解释、转折和例子说明。
- 板书负责留痕：概念、关系、步骤、代码和验收。
- 代码板书以 `|` 开头，`|` 只用于分隔黑板行。
- 代码不能进入旁白和 SRT。

加载内容后要统一规范化。如果扩展内容把 `(代码, 说明)` 写反，应转换成：

```python
(spoken_explanation, code_on_board)
```

修改旁白后给音频缓存换版本名，避免复用旧 TTS。

### 首屏

第一帧必须有：

- 章节号。
- 章节名称。
- 老师。

保持到开场旁白结束，再进入正文。封面保持期间，字幕仍要从第一句旁白开始。

### 正文

每个知识页至少展示：

- 概念。
- 规则或作用。
- 最小例子。
- 一个边界或常见错误。

不要只放一个标签。关键概念要在黑板留痕。

### 练习

练习必须是独立场景，板书展示：

1. 题目。
2. 流程。
3. 左右实现面板。
4. 验收标准。

题目名称同时写进场景标题和片尾。

### 回顾

片尾必须包含本章具体概念、验证边界、练习名称和下一章。不要使用通用标题代替本章内容。

### 技术词

- CPU 主频写 `3.0 GHz` 或“三点零吉赫兹”。
- 中文问号直接跟在句子后。
- 不要让问号或句号孤立换行。
- 中英文和数字之间保留空格。

## 工作流

### 1. 检查现状

```bash
python scripts/check_outputs.py --output-dir outputs --min-seconds 180
```

查看：

- MP4、SRT、timeline 是否齐全。
- 每章时长。
- SRT 是否出现代码管道符。
- 场景和 beat 数。
- 是否包含练习场景。

### 2. 修改内容

在 `content/remaining_chapters.py` 修改对应章节。先改正文，再改练习，最后改回顾。

如果只做静帧检查，运行：

```bash
python scripts/build_ch02.py --chapter 12 --preview
```

查看 `outputs/preview/ch12/` 中的：

- 封面。
- 开场字幕。
- 练习页。
- 片尾。

### 3. 渲染

```bash
python scripts/build_ch02.py --chapter 12 --reuse-audio
```

首次生成会合成缺失旁白。修改文案后，确认缓存版本已变化或清理旧缓存。

### 4. 审查

抽查：

- 第一帧。
- 开场旁白结束处。
- 每个练习页。
- 片尾。
- 代码缩进和行宽。
- SRT。

必要时把章节拆给多个审查任务，每个任务只负责 2–3 章，并返回具体时间点和问题。

### 5. 交付

MP4、SRT、timeline 同名归档。大文件不要提交到普通 Git 历史；使用对象存储或 GitHub Release。

## 常见故障

### 成片只有 1 分多钟

先查 `SCENES` 是否真的包含扩展场景，再查 timeline 的场景和 beat 数，最后查音频是否复用旧缓存。

### 字幕出现 `|代码|`

内容中把代码放在 `say` 字段，或 tuple 顺序反了。统一规范化 beat，并更换音频缓存版本。

### terminal 代码缩进消失

渲染前对代码行调用了 `strip()`，或内容作者写入了单行代码。保留行首空格，每个换行对应一个黑板行。

### 代码越界

按每行实际宽度逐级缩小字体。不要让所有行统一使用最小字号，也不要只按字符数估算。

### 首屏是正文

`scene_starts[1]` 之前应始终渲染封面。封面保持逻辑不能把字幕一起隐藏。

## 验收

全部通过才交付：

- 15 章 MP4、SRT、timeline 齐全。
- 每章 3–5 分钟。
- 首屏和开场字幕正确。
- 练习页完整。
- 回顾具体。
- SRT 无代码符号。
- 代码可读。
- YouTube 元数据完整。
